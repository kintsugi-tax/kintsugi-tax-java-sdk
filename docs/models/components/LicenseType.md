# LicenseType

Louisiana license type, which determines the filing portal: Direct Marketers file using the Louisiana DOR LaTAP website, Remote Sellers file using the Remote Sellers website, and Standard license types file using the Parish E-File website.

## Example Usage

```java
import com.kintsugi.taxplatform.models.components.LicenseType;

LicenseType value = LicenseType.DIRECT_MARKETER;
```


## Values

| Name              | Value             |
| ----------------- | ----------------- |
| `DIRECT_MARKETER` | DIRECT_MARKETER   |
| `REMOTE_SELLER`   | REMOTE_SELLER     |
| `STANDARD`        | STANDARD          |
