# NevadaFields

State-specific fields for Nevada (My Nevada Tax) registration import.


## Fields

| Field                                                                                                              | Type                                                                                                               | Required                                                                                                           | Description                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `mfaCompleted`                                                                                                     | *Optional\<Boolean>*                                                                                               | :heavy_minus_sign:                                                                                                 | Whether the customer has completed MFA setup using the Kintsugi virtual mail group ID on their Nevada tax account. |
| `registrationType`                                                                                                 | *String*                                                                                                           | :heavy_check_mark:                                                                                                 | Registration type for this Nevada import: sales and use tax.                                                       |
| `businessName`                                                                                                     | *String*                                                                                                           | :heavy_check_mark:                                                                                                 | State-registered business name as shown in My Nevada Tax.                                                          |
| `nvStateTaxId`                                                                                                     | *String*                                                                                                           | :heavy_check_mark:                                                                                                 | Nevada state-issued tax identification number (NV State Tax ID).                                                   |
